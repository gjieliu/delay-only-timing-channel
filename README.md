# Numerical production code for capacity bounds of delay-only timing channels with bounded dwell

This repository contains the numerical production code that generates every number reported in

> G. Liu, W. Liu and H. Ding, "Capacity Bounds for Delay-Only Timing Channels with Bounded Dwell," submitted to *IEEE Transactions on Information Theory*, 2026.

The paper gives two-sided bounds on the capacity of a delay-only, packet timing channel under a bounded-dwell budget:

```
C_0 - Delta_+  <=  C  <=  C_0 - Delta_- + o(1),   C_0 = log2( B / (sqrt(2*pi*e) * sigma) ),
```

where `Delta_+` is the achievable endpoint from the multiresolution modulo-lattice construction and `Delta_-` is the converse endpoint from the corridor-volume exponent. The scripts in this repository compute these two endpoints for a set of host processes, produce a global certificate for `Delta_+` on the three independent hosts of Table II, and draw the figures.

**This repository tracks source only.** The result JSON files and figure PDFs are build artifacts and are excluded by `.gitignore`; they are regenerated by running the scripts. Which script produces which number in the paper, into which output field, and what value a fresh run should give is listed entry by entry in `MANIFEST.md`, so a reader can verify their own run without our copies of the outputs.

The layout is flat: all scripts live at the repository root, and running them creates `result/` (JSON) and `fig/` (PDF) at the same level; neither is tracked.

All scripts except `make_fig2.py` are byte-identical to the production chain; their comments and in-code notes remain in Chinese, untranslated, so that this repository's code is provably the code that produced the paper's numbers.

## Dependencies

Python >= 3.9, NumPy >= 1.22, SciPy (bounded 1-D search for the tiering ratio), mpmath (80-digit interval arithmetic for the `Delta_+` certificate); `make_figs.py` and `make_fig2.py` additionally require Matplotlib. See `requirements.txt`.

Two version records are given here, side by side, without post-hoc unification:

* Monte Carlo and quadrature results were produced with **Python 3.11.15 + NumPy 2.4.4**;
* the `Delta_+` global certificate was produced with **Python 3.12.2 + mpmath 1.3.0 + SciPy 1.18.0** (each run writes the then-current versions into the `software` field of the certificate output).

All random streams are derived from explicit seeds through `numpy.random.default_rng`, and are bit-for-bit reproducible under the same NumPy version; the certificate and multiresolution baselines are deterministic.

The flat layout of this repository was verified by an actual run on a third configuration (**Python 3.11.15 + mpmath 1.4.1 + SciPy 1.17.1**):

* `certify_delta_plus.py` produces bit-identical output apart from the `software` field that records the run version — the same interval `[2.5479514302830033, 2.5480013506287813]`, the same `beta_star_interval`, the same `adaptive_splits` = 2116;
* `multires_bound.py` matches the production result field by field, with the **single exception** of the `beta_hat` of the host `Exp(mean=B)` not tabulated in the paper body (4.187529 vs 4.187528) — a sixth-decimal difference within the tolerance of SciPy's bounded search; every quantity cited in the paper body is unaffected;
* `test_multires.py` passes (run `certify_delta_plus.py` first to generate the certificate);
* the Fig. 2 redraw flow runs to completion with the commands in the next section, and the slice is identical to `fig2_data.json` in the submission package.

## Redrawing Figure 2 of the paper

The Fig. 2 printed in the English manuscript is drawn by `make_fig2.py`, which changes only labels, fonts and canvas size and recomputes no value. It reads `fig2_data.json` — a verbatim slice of the `Exp(mean=2B)` key from `result/multires.json`. After the full run:

    python3 -c "import json;d=json.load(open('result/multires.json'));json.dump({'source':'result/multires.json key \"Exp(mean=2B)\"','Exp(mean=2B)':d['Exp(mean=2B)']},open('fig2_data.json','w'),indent=1)"
    python3 make_fig2.py        # -> fig_multires_gap.pdf

The redraw is identical to the PDF in the submission package except for the embedded `/CreationDate` timestamp.

## About `check_consistency.py`

This script is a machine check that "every number in the paper matches the JSON." It is included here for completeness but **cannot run standalone inside this repository**: it reads the authors' internal manuscript tree (`../manuscript/main.tex`, `../manuscript/appendix_proofs.tex`, `../sketelon.md`, `../design.md`, `../manuscript/supplement/numerical_evidence.md`), which is not published with this repository. To verify the paper's numbers, use `MANIFEST.md`, which lists the correspondences and expected values entry by entry.

## Methodology and evidence levels

The Python layer and JSON schema use `J_beta` for the fixed-$\beta$ construction cost, `beta_hat` and `J_beta_hat` for the candidate ratio from the SciPy bounded 1-D search over $\beta\in[1.02,20]$ and its fixed-design cost, and `Delta_minus` for the corridor-loss lower end. This local search does **not** emit `beta_star` or `Delta_plus`; the theoretical endpoints remain $\Delta_+=\inf_{\beta>1}J_\beta$.

The paper strictly distinguishes "certified" from "estimated," and the code keeps the same vocabulary:

* **Certified.** $\Delta_+$ for the three independent hosts of Table II. The exponential host uses analytic-endpoint exclusion plus a probability-enclosure branch-and-bound that covers all $\beta>1$ under 80-digit arithmetic, with certificate width < 5×10⁻⁵; the two uniform hosts have zero-width analytic intervals.
* **Deterministic estimate, not a certificate.** The corridor exponent and the $\Delta_-$ derived from it are a fixed-grid discretization of the volume exponent, not a continuous-operator certificate; grid sensitivity is written to the output.
* **Monte Carlo estimate.** The GMI constant $c_1$ and the finite-noise GMI value are Monte Carlo estimates with standard errors, and the paper cites them in that wording.
* **Fixed-design bound only.** `J_beta_hat` is only the provable fixed-design bound at the candidate point; the correlated host's `J_sel` is likewise a fixed-design bound and is outside the global-certification scope.

Randomness and self-checks: `gmi_demo.py`'s stationary-dwell pool is a deterministic equidistant dilution of the trajectory, and the evaluating strategy alphabet is drawn from an independent random stream; `gmi_finite.py`'s evaluating dwell is taken from an independent trajectory (seed+7000). `correlation_full.py` has built-in grid (800/1600/3200) and path-length self-checks; `gmi_demo.py` has a built-in paired-perturbation self-check on the shared random stream; `gmi_finite.py` has a built-in nested-error self-check on the reference-density pool and mixed samples.
